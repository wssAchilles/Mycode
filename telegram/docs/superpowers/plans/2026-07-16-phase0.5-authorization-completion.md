### 0.2 学术总判定

**CONDITIONAL GO。** Phase 0.5 原则（每向量契约、维度不充分、replay≠历史执行、mixed-lineage 非破坏隔离、metadata-only）与 PROV / BCT 系 / 向量库迁移实践同向。缺口是工程机制，不是算法错误。

### 0.3 必须写死的限定语句（本 plan 的 Normative Constraints）

1. **血缘限定**：`verified_local_fallback` 仅表示与当前确定性生成契约的实现-输入元组一致，或经批准写入路径的结构匹配；**不**构成 PROV `wasGeneratedBy` 级历史执行证明。
2. **隔离限定**：`quarantined` 为非破坏、fail-closed 的工程隔离，依据批准的 count + identity digest；**不**表示已诊断混合血缘成因，**不**自动转正。
3. **兼容与评估限定**：跨生成 embedding 兼容仅可在 BCT/FCT/AdvBCT 式显式训练 + 跨代检索评测后宣称；Phase 0.5 metadata-only 修复**不得**被解释为语义兼容、ANN 就绪或 recall@K 改善；`semantic_ready` 在本阶段词表保留但不可达。
4. **权威 apply 证据**只能在 writer pause（或已批准且有 artifact 证明的 snapshot 窗口）下生成；pause 后必须重跑 full dry-run；apply 只能绑定 pause 后的 proposal/backup digest。
5. **Apply/rollback 严禁自我批准**：proposal/quarantine/backup digest 必须来自外部审阅 artifact。
6. **Metadata-only 写路径不变量**：`twoTowerEmbedding` / `phoenixEmbedding` / `denseEmbedding` 出现在 set/unset ⇒ 首个写之前失败；向量 checksum 漂移 ⇒ writeCounters 全 0。
7. **Release gate** 只接受 full strict + 外部已批 quarantine digest；`--limit`、采样、baseline exit 2、空 export 不得写入「Phase 0.5 complete: YES」。
8. **Phase 0.5 完成 ≠ ANN/semantic 就绪**；Python feature refresh writer 在具备 atomic vector+contract 写路径并单独授权前保持禁用。
9. **不采用** Qdrant blue-green dual-write + re-embed 作为本阶段主路径（那是模型迁移模式，保留给 Phase 1+）。

### 0.4 显式安全假设（写入 authorization packet 语境）

信任根（approval 文件带外可信、无数字签名）；writer pause 覆盖全部可写路径；Mongo snapshot ≠ PostgreSQL 一致性；SHA-256 抗碰撞 + 规范化编码无歧义；非恶意运维；主机时钟大致同步；pause 窗口内集合不再插入；storage∧ANN 失效模式足够独立；metadata-only backup 对回滚充分。

## 4. Task 8 刷新 SOP（operator 凭据就绪后）

```text
1. 确认 O2 完成：git diff --name-only -- ml-services 为空；code-state 可绑定
2. 归档旧 packet（禁止与新 packet 混用）
3. 重跑 A1 全套 + git diff --check → 新 deterministic-checks.json
4. 全量默认 dry-run（无 limit）→ proposal.json
   npm --prefix telegram-clone-backend run backfill:embedding-contracts -- \
     > reports/recommendation/embedding-contract-remediation/proposal.json
5. 独立 proposal reviewer（非同进程）→ proposal-review.json
   必须 approved；REJECT 则停，不生成 packet
6. 可选 baseline strict：exit 0|2 可记录；3/信号/malformed 阻断
7. 写 dispatch-evidence.json（agentId/model/effort 实录）
8. 跑 renderEmbeddingRemediationAuthorizationPacket → authorization-packet.md + SHA256SUMS
9. packet 必须仍含：CODE_AND_DRY_RUN_READY / NOT GRANTED / Task 9 UNAUTHORIZED / Phase 0.5 complete: NO
10. shasum -a 256 -c SHA256SUMS 通过后停
```

禁止：apply/rollback、cache 删除、scheduler 变更、`verify_all.sh`、Python 操作。

## 5. Task 9 生产 SOP（仅 O4 显式授权后）

```text
1. 两份生产授权 JSON：apply 与 rollback（operation 匹配；绑定 proposal/backup digest + Mongo URI hash + 过期）
2. Pause writers：Node daily refresh/export + Python feature refresh（不改 Python 源）
   证明：无旧 Node 实例可写 UserFeatureVector → writer-pause-evidence.json
3. Pause 后重跑 full dry-run + backup → post-pause-proposal.json
4. 外部再批 proposal + backup（chronology: pause ≤ approval ≤ authorize）
5. Apply：digest-bound、metadata-only、bounded bulkWrite
   任一 preflight 失败 ⇒ writeCounters 全 0
6. Cache/process：只删授权的 fcs:emb:* 与 sc:embed:*；roll Node 或等 L1 TTL
   不恢复 Python writer
7. Post-apply full strict exit 0（quarantine count=4 且 digest 匹配）
8. 唯一一次 Phase 0.5 verify_all.sh
9. 失败 ⇒ 独立授权的 metadata-only rollback + 再失效缓存 + 只读 audit 落盘
10. 双 gate 通过后才恢复已批准 Node jobs；packet 置 Phase 0.5 gate complete: YES
```

**推荐补强（可选，需另开小任务）：** apply 后全集合非 metadata 字段 checksum 二次对账报告；clobber-fix 部署证明的机器可读 artifact。
