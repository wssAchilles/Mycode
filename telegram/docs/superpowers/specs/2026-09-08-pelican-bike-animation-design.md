# 鹈鹕骑自行车 SVG 动画设计

## 目标

新增一个可以直接双击打开的独立 HTML 文件，展示鹈鹕骑自行车的循环 2D 动画，不依赖现有前端、构建工具、第三方库或外部图片资源。

## 视觉与布局

- 采用明快童书风：奶油色天空、柔和云朵、远山、草地和一条暖色道路。
- 画布使用 `viewBox="0 0 960 620"` 的响应式 SVG，适配桌面和窄屏宽度并保持比例。
- 鹈鹕和自行车位于前景中央偏下，轮子、车架、脚踏、身体、翅膀和喙使用基础 SVG 图形绘制。
- 通过远近两层云、道路虚线和轻微的角色起伏制造运动感，画面保持简洁可读。

## 动画行为

- 车轮和脚踏持续旋转，车轮辐条与脚踏共用稳定的循环节奏。
- 鹈鹕身体上下轻微起伏，翅膀以更慢的节奏摆动，模拟保持平衡。
- 云朵和道路虚线水平移动，形成自行车前进的错觉。
- 使用 CSS `@keyframes` 驱动 SVG，避免 JavaScript 时间循环和额外依赖。
- 在 `prefers-reduced-motion: reduce` 下暂停运动并保留完整静态画面。

## 文件边界

- 新增 `pelican-bike.html`：包含 HTML、SVG、CSS 和必要的 SVG 元数据。
- 不修改现有 React 前端、后端或当前工作区已有改动。

## 验收标准

1. 直接打开 `pelican-bike.html` 后无需启动服务器即可看到完整场景。
2. 画面能清楚表达鹈鹕坐在自行车上骑行，并且主要运动持续循环。
3. 窗口缩放时 SVG 不变形、不溢出页面。
4. 浏览器开启减少动态效果偏好时，页面不再持续运动。
5. HTML 不包含外部请求、框架引用或运行时错误。

## 验证

- 用浏览器打开文件，检查动画首屏、缩放和减少动态效果样式。
- 用文本检查确认文件只有预期的新增内容，并用 HTML/CSS 结构检查确认关键 SVG 分组和动画类存在。
