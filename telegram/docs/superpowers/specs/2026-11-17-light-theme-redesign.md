# 全站淡色极简重构设计规范 (X Light & Telegram Light)

**日期**: 2026-11-17  
**状态**: 待审批  
**设计依据**: [MASTER.md](file:///Users/achilles/Documents/telegram_code/telegram/design-system/telegram-space-light/MASTER.md) 及用户提供的 X 淡色三栏参考图

---

## 1. 改造目标与边界

将前端从当前的“暗黑玻璃拟态套娃风”彻底重构为**纯净淡色高对比度极简风**：
- **纯白画布 + 深色高对比文本**：全站默认浅色主题，主文 `#0F1419` 与次级文字 `#536471` 严格满足 WCAG AA/AAA 可读性标准。
- **消除所有硬编码暗黑残留**：系统清洗 `src/` 下 59 个 CSS 文件与 TSX 内联样式中写死的白色文本、深黑遮罩、暗蓝卡片底色及紫蓝渐变光晕。
- **零功能退化**：不改变现有业务逻辑、路由契约、推荐流排序、Web Worker 同步、表单校验及可访问性（`aria-*`、焦点环、`prefers-reduced-motion`）。

---

## 2. 备选方案评估（Approaches）

在确立设计前，对比了以下实现路径：
1. **方案一（仅替换 CSS 变量）**：只修改 `index.css` 中 `:root` 的少数变量。**否决原因**：经 grep 扫描，全站 59 个 CSS 文件存在 600+ 处写死的深色/白色硬编码色值（如 `SpaceProfilePage.css` 90 处、`AuthPages.css` 54 处、`SpacePost.css` 50 处、`ChatPage.css` 43 处），仅改 `:root` 会导致白底白字与黑块拼贴错乱。
2. **方案二（彻底双层解耦：全局淡色 Token 体系 + 关键页面布局去框重构，选定方案）**：
   - **底层**：重写 `index.css` 为语义化淡色 Token（`#FFFFFF` 画布、`#F7F9F9` 浅灰面板、`#EFF3F4` 发丝分割线、`#0F1419` 深炭黑正文字体、`#536471` 石板灰辅助字体、`#1D9BF0` 品牌蓝与 `#0F1419` 黑胶囊 CTA）。
   - **结构重塑**：对 Space 三栏、Chat 双/三栏、Profile 主页、登录/注册页做无框化与无缝化布局重构，彻底消灭套娃边框、虚线占位框、粗饱和蓝条、遮挡悬浮圆钮与顶栏暗块断层。

## 3. 各核心页面与模块视觉重构方案

### 3.1 Space 首页 (`SpacePage.css` / `SpaceTimeline.css` / `SpacePost.css` / `PostComposer.css` / `SpaceAsideWidgets.tsx`)
严格对标 X (Twitter) 淡色经典三栏结构：
- **整体骨架**：去除视口外圈 `20px` padding 与三栏圆角盒子阴影，改为全高纯白三栏平铺（左导航 `260px` | 中主栏 `minmax(600px, 680px)` | 右侧栏 `320~350px`），栏间仅用 `1px solid #EFF3F4` 竖线分隔。
- **左侧导航**：
  - 顶部保留精简品牌图标，导航项无框线，悬停呈浅灰胶囊 `#EFF3F4`，激活项图标与字重加粗至 `700`（`#0F1419`）。
  - 主 CTA “发布动态” 改为高对比纯黑大胶囊（`background: #0F1419; color: #FFFFFF; border-radius: 9999px`），Hover 为 `#272C30`。
  - 底部个人信息区去框极简展示，悬停淡淡浅灰。
- **中间主时间线**：
  - 粘性顶栏采用磨砂白 `rgba(255, 255, 255, 0.85)` + `backdrop-filter: blur(12px)`；“全部 / 好友” Tab 改为 **X 式全宽底边蓝色下划线切换条**（选中态 `#0F1419` 加粗 + 底部 `3px` 蓝色指示条 `#1D9BF0`）。
  - 发帖区、今日时事速递、动态流条目全部取消外围圆角框，改为全宽平铺 + `1px solid #EFF3F4` 底分割线；单条动态悬停为极轻 `rgba(0, 0, 0, 0.018)`；互动按钮采用 X 标志性微交互反馈色（评论蓝、转发绿 `#00BA7C`、点赞粉红 `#F91880`）。
  - 来源/推荐标签转为克制的浅灰微胶囊（`#F7F9F9` 底 + `#536471` 字），不抢正文视觉重心。
- **右侧栏**：
  - 去除“推荐系统状态”与“热门趋势”的粗亮蓝进度条；趋势与推荐关注包裹在干净无描边 `#F7F9F9` 圆角（`16px`）面板中，“关注”按钮采用纯黑胶囊 `#0F1419` 白字（已关注为描边白胶囊），数字采用 `tabular-nums` 等宽对齐。

### 3.2 Chat 即时通讯页 (`ChatPage.css` / `ChatHeader.css` / `ChatListItem.css` / `MessageBubble.css` / `MessageInput.css` / `GroupDetailPanel.css`)
- **整体骨架**：参考 Telegram Web Light / Apple Messages 淡色设计。去除外围 `18px` 深色间隙和 `::before/::after` 氛围光球；左侧会话列表 `#FFFFFF` 搭配 `1px solid #EFF3F4` 右侧分隔线；右侧主聊天区采用极淡纯净冷灰背景 `#F4F6F8`（或极浅水洗白 `#F8FAFC`）让气泡自然浮起。
- **侧边栏精修**：
  - 去掉“+ 新建群组”的丑陋虚线框，收拢为侧边栏顶部精简的浅灰/透明图标按钮或低调实线操作条。
  - **去掉右下角遮挡列表的巨大蓝绿渐变圆形 FAB**，将“添加联系人”与“新建群组”优雅收纳于顶部功能区，保持列表底部的完全可读性。
  - 会话选中态使用清爽浅天蓝底色 `rgba(29, 155, 240, 0.12)` + 左侧细蓝条（文字严格保持深色 `#0F1419` / `#536471`，保证高对比度！）。
  - 默认首字母头像采用柔和低饱和莫兰迪/马卡龙调色，不再用刺眼高饱和渐变加横杠。
- **聊天顶栏 (`ChatHeader`)**：修复左侧与搜索框之间的深色断层块，统一为通体纯粹的磨砂白顶栏 `#FFFFFF/88%` + `1px solid #EFF3F4` 底线；搜索框为圆润 `#EFF3F4` 浅灰胶囊。
- **消息气泡 (`MessageBubble`)**：
  - 己方消息：纯净 Telegram 经典天蓝 `#1D9BF0`（或 `#2AABEE`）+ 纯白文本（对比度需清晰，时间文字使用 `rgba(255,255,255,0.88)`）；
  - 对方消息：纯白气泡 `#FFFFFF` + 极轻微阴影 `0 1px 2px rgba(15, 20, 25, 0.06)` + 极浅灰描边 `#E6ECF0` + 深炭黑文本 `#0F1419` + `#536471` 时间戳；保留此前修复的已读徽章 `padding-top` 防裁剪保护。
- **输入栏 (`MessageInput`)**：纯白/浅灰圆角胶囊输入槽，深色输入文字，清爽蓝色发送按钮。

### 3.3 个人主页、详情页与探索/通知 (`SpaceProfilePage.css` / `SpaceExplore.css` / `SpaceNotifications.css` / `NewsDetailPage.css` / `SpacePostDetailPage.css`)
- **个人主页 (`SpaceProfilePage`)**：
  - 消除顶部浮空胶囊和卡片间的孤立裂缝，改为类似 X 个人主页的一体化居中主栏（`max-width: 680px` 或双栏，`border-inline: 1px solid #EFF3F4`）；
  - 封面图无外框平铺在顶部，头像底部半重叠压在封面左下角，带 `4px solid #FFFFFF` 白色描边；“编辑资料 / 更换头像 / 关注”按钮采用规范的实心黑胶囊或白色细描边胶囊（彻底删除虚线边框）；
  - Tab 栏（动态/媒体/喜欢/不喜欢）统一为 X 式底边蓝线 Tab 栏。
- **探索、通知、新闻与动态详情**：全部统一到纯白背景 `#FFFFFF`、浅灰输入/筛选块 `#EFF3F4` 与 `#0F1419` / `#536471` 文本系统。

### 3.4 登录、注册、引导与 404/管理后台 (`AuthPages.css` / `OnboardingPage.css` / `Dashboard.css` / `routes/index.tsx`)
- **登录/注册页**：采用干净优雅的淡色左右分栏（或居中纯净白卡片搭配极淡中性浅灰底 `#F7F9F9`），消除背景中那层错位且多余的透明外框和发光球，对齐卡片边距；输入框使用 `#FFFFFF` 背景 + `#CFD9DE` 细框线 + `#0F1419` 深色输入文本；主按钮改为纯黑胶囊或纯正天蓝，无廉价紫蓝渐变。
- **404 与管理面板**：替换紫色渐变按钮与暗黑图表背景，适配淡色表面与清晰深色文字。

## 4. 质量与验证门禁

1. **全量对比度与暗色残留扫描**：改造后执行 grep 扫描，确认无残留的暗色硬编码底色（如 `#0A0D12`、`#151D2A`、`rgba(16, 23, 34`）与导致白底看不清的浅白字色。
2. **TypeScript 与全量构建/测试验证**：运行 `tsc --noEmit`、Vitest 单元测试（确保现有 A11y/隔离/气泡测试全绿）以及 `vite build`。
3. **部署与 Chrome DevTools 实机全页视觉验收**：构建部署到 Firebase Hosting 后，用 `chrome-devtools` 逐一打开登录页、Chat 聊天界面、Space 首页（全部/好友/探索/通知）、个人主页并截图检查真实渲染与文字对比度。
